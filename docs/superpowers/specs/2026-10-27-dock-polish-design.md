# Dock UI 다듬기: by ssenu 위치, 말풍선 깨짐, 메뉴 정리, 알림 이름

작성: 2026-10-27 · 대상 버전: 0.2.5

## 목표

1. `by ssenu`를 독 판 **안** 끝에 연한 글씨로 넣는다.
2. 독 아이콘 이름 말풍선의 깜빡임·잔상, 잘림, 거친 모서리를 없앤다.
3. 트레이 메뉴에서 독 위치(아래·위·왼쪽·오른쪽) 4줄을 뺀다. 위치는 독 수정 모드에서 끌어서 바꾼다.
4. 윈도우 알림(트레이 풍선) 머리글에 `YT Launcher` 대신 `Dock UI`가 보이게 한다.

## 1. by ssenu: 판 끝 글자 칸

- `DockLayout`에 마지막 칸 뒤 **글자 칸**(아이콘 칸 아님)을 둔다.
  - 가로 독: 폭 `CREDIT_W = 36` DIP, 세로 독: 높이 `CREDIT_H = 30` DIP.
  - 수정 모드에서도 맨 끝(✓ 단추 뒤)에 있다.
  - 판 길이(`length`)에 포함되고, 확대 배치(`magnified`)에서도 같은 크기로 끝에 붙는다.
- 그리기: `by` / `ssenu` 두 줄, 9 DIP SemiBold, 색은 테마 `subtext`의 알파 0.55. 글자 칸 가운데 정렬.
- 클릭 판정: 글자 칸은 `Hit::Empty` (수정 모드에서는 판 옮기기 자리).
- 지운다: 판 아래 알약 글씨(`credit_rect`, `draw_credit`), 아래 독 추가 여백(`edge_margin`의 `CREDIT_H`), 콘텐츠 창 `footer`.

## 2. 말풍선: 표시 영역 2단계 고정 + 페이드 + 픽셀 맞춤

원인: 독 콘텐츠 창의 `SetWindowRgn`을 확대 애니메이션 매 프레임마다 말풍선 크기로 바꾸는데, 영역은 즉시 바뀌고 새 그림은 다음 화면 합성에 올라와 한 프레임씩 어긋난다(잘림·잔상). 말풍선 위치가 픽셀 경계에 맞지 않아 배율에 따라 테두리·모서리가 뭉개진다.

- **영역 상태 두 가지** (`Panel`의 `region_active: bool`):
  - 쉼: 판 사각형 (+ 수정 모드면 안내 사각형).
  - 활성: 콘텐츠 창 전체.
  - 쉼 → 활성: 독 모드에서 마우스가 판 위에서 움직일 때 (`on_mouse_move`).
  - 활성 → 쉼: 확대 정도 `amount`가 0이고 말풍선 불투명도도 0일 때 (`tick`에서 애니메이션이 멈출 때), 끌기·판 옮기기 중이 아닐 때.
  - 영역은 상태가 바뀔 때만 설정한다 (지금의 `last_region` 비교 유지).
- **말풍선 페이드**: `Anim` 하나(`tooltip_alpha`)를 말풍선 대상이 있으면 1, 없으면 0으로. 약 120ms에 도달하도록 속도를 둔다. 사라질 때 마지막 대상 칸을 기억해 그 자리에서 사라지게 한다. `draw_tooltip_box`에 불투명도 인자를 더해 바탕·테두리·글자 알파에 곱한다.
- **픽셀 맞춤**: 장면에 그리기 배율(`px_scale`)을 넘겨 말풍선 사각형의 x·y·w·h를 `round(v * scale) / scale`로 맞추고, 1px 테두리는 `0.5 / scale` 안쪽에 그린다. 패널 말풍선에도 같은 함수를 쓴다.

## 3. 트레이 메뉴 정리

- `CMD_EDGE_BOTTOM/TOP/LEFT/RIGHT` 메뉴 줄·처리·`set_edge`를 지운다.
- 독 모드일 때 메뉴: `독 모드 ✓` 아래 `독 수정 모드 (옮기기·크기·순서)` 한 줄만.
- `PanelCmd::SetDockPlacement`는 다른 곳에서 쓰지 않으면 함께 지운다.

## 4. 알림 이름: 버전 정보 + 앱 ID

- `app.rc`에 `VERSIONINFO`: `FileDescription`·`ProductName` = `Dock UI`, `CompanyName` = `ssenu`, `OriginalFilename` = `YTLauncher.exe`, 버전 숫자는 `build.rs`가 `CARGO_PKG_VERSION_*`를 매크로로 넘긴다 (릴리스 워크플로가 태그 버전을 `Cargo.toml`에 반영한 뒤 빌드하므로 그대로 맞는다).
- 시작할 때 `SetCurrentProcessExplicitAppUserModelID("ssenu.DockUI")`.
- 설치 프로그램 `[Icons]` 두 바로가기에 `AppUserModelID: "ssenu.DockUI"`.
- 바꾸지 않는다: exe 이름, 설치 파일 이름, 설정 폴더, 뮤텍스, Run 값 (업데이트 호환).
- 알려진 한계: 앱 ID가 바뀌어 윈도우 알림 설정이 새 앱으로 잡힌다(허용 기본값). 이 버전을 설치하기 전의 업데이트 알림은 옛 버전이 띄우므로 옛 이름일 수 있다.

## 테스트

- 단위: 글자 칸이 있는 독 길이·마지막 칸 뒤 위치·`Hit::Empty`, 수정 모드에서 ✓ 뒤에 있음, 영역 상태 전이 함수(순수 함수로 분리: 입력 = 확대 정도·말풍선 불투명도·끌기 여부·마우스 위 여부 → 활성 여부), 픽셀 맞춤 함수, 메뉴 항목에 독 위치 줄이 없음.
- 스냅샷: 가로·세로·수정 모드 독(글자 칸), 말풍선 불투명도 0.5 상태.
- 리소스: 빌드한 exe의 버전 정보에 `Dock UI`가 있는지 (PowerShell `VersionInfo`로 확인).
- 수동(점검표): 독 위에서 좌우로 빠르게 움직여도 말풍선이 잘리거나 잔상이 없음, 125%/150% 배율에서 모서리 또렷, 알림 머리글 `Dock UI`.
