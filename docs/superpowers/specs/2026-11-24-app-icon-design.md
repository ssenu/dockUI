# 앱 아이콘을 보라 타일 격자로 (0.3.0)

작성: 2026-11-24 · 대상 버전: 0.3.0 (아직 릴리스 전인 이름 변경과 함께)

유튜브 재생 버튼 모양인 앱 아이콘을 Dock UI에 맞는 아이콘으로 바꾼다. 브라우저 시안 비교에서 "B1. 보라 타일 격자"를 골랐다.

## 모양 (256 단위 좌표)

- 판: `(12, 12)`에서 `232×232`, 모서리 반지름 56. 대각선(왼쪽 위 → 오른쪽 아래) 그라데이션 `#6A7CF7` → `#8E4FD8`. 판 바깥은 투명.
- 흰 타일 네 칸, 각 `66×66`, 모서리 반지름 18:
  - 왼쪽 위 `(54, 54)` 불투명도 1.0
  - 오른쪽 위 `(136, 54)` 0.55
  - 왼쪽 아래 `(54, 136)` 0.55
  - 오른쪽 아래 `(136, 136)` 0.85

## 만드는 방법

- 앱의 Direct2D 그리기(`Gfx::offscreen`)로 각 크기를 따로 그린다(큰 그림을 줄이지 않는다). 그리기 좌표는 256 단위, 배율 `크기/256`.
- 생성은 무시(`#[ignore]`) 테스트로 둔다: `cargo test generate_app_icon -- --ignored`. 결과:
  - `assets/icon.png`: 256×256 PNG
  - `assets/icon.ico`: 16, 20, 24, 32, 40, 48, 64, 256px 프레임. 각 프레임은 PNG로 넣는다(Vista 이후 지원). ICO 헤더·디렉터리는 직접 쓴다.
- PNG는 투명도가 곱해지지 않은(straight) 32bpp BGRA로 저장한다. Direct2D 그림은 곱해진(premultiplied) BGRA이므로 WIC 형식 변환을 거친다. 변환하지 않으면 반투명 가장자리가 어두워진다.
- 대각선 그라데이션을 위해 `Gfx`에 시작점·끝점을 받는 둥근 사각형 그라데이션 채우기를 더하고, 기존 위→아래 함수는 그것을 부르게 한다.

## 적용 범위

- 실행 파일 아이콘(`build.rs`가 `icon.ico`를 넣음), 트레이(실행 파일 리소스), 설치 프로그램(`SetupIconFile`)이 이 두 파일로 함께 바뀐다. 코드에서 아이콘을 쓰는 곳은 고치지 않는다.
- 독 안의 유튜브 항목 타일 그림은 "유튜브 검색 항목"을 뜻하므로 그대로 둔다.
- 테스트 자료로 `assets/icon.png`를 쓰는 테스트(파비콘 저장, 장면 스냅숏)는 새 그림으로도 그대로 통과해야 한다.

## 테스트

- 무시하지 않는 테스트: `assets/icon.ico`가 프레임 8개, 크기 순서 16·20·24·32·40·48·64·256, 각 프레임이 PNG 시그니처로 시작하고 디렉터리의 크기·오프셋이 파일과 맞는지. `assets/icon.png`가 256×256인지.
- 눈으로: 생성된 256·32·16px 그림을 확대해 확인한다.
- 업데이트 직후 윈도우 아이콘 캐시 때문에 바로가기에 옛 아이콘이 잠깐 남을 수 있다(다시 로그인하면 바뀜). 점검표에 적는다.
