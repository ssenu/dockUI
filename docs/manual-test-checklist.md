# 릴리스 전 수동 점검표

빌드된 설치 프로그램으로 실제 Windows 11에서 확인한다.

## 독 모드
- [ ] 새 설치 첫 실행 시 화면 아래 가운데(작업표시줄 위 8px)에 독이 뜬다
- [ ] 작업표시줄에 아이콘이 없고 트레이 아이콘만 있다
- [ ] 다른 창을 열면 독이 그 뒤로 깔린다. Win+D 뒤에도 보인다
- [ ] 마우스를 올리면 아이콘이 물결처럼 커지고 이웃이 밀리며, 이름 말풍선이 화면 안쪽에 뜬다
- [ ] 독 위 빈 곳·독 옆 바탕화면 클릭이 막히지 않는다
- [ ] 독에는 항목 아이콘만 있다(항목이 없으면 ＋ 하나). 긴 이름에 마우스를 올려도 말풍선에 이름 전체가 나오고, 아주 길면 여러 줄로 바뀐다(아래·왼쪽·오른쪽 독 모두)
- [ ] 독 수정 모드에서 끌어 위·왼쪽·오른쪽으로 옮겨 간다(왼쪽·오른쪽은 세로 독)
- [ ] 해상도나 작업표시줄 위치를 바꾸면 독이 다시 자리를 잡는다

## 패널 모드
- [ ] 트레이 메뉴 → 패널 모드로 바꾸면 우상단 창으로 바뀐다
- [ ] 이동·크기 조절, 위치 잠금, 위치·크기 초기화, 재시작 후 위치 복원

## 항목
- [ ] ＋(패널) 또는 트레이 메뉴 → 항목 추가… → 유튜브: 검색어 저장 → 클릭하면 크롬 최대화 창에 검색 결과(크롬이 켜져 있으면 새 탭)
- [ ] 항목 추가 → 앱 → [앱 고르기]: 목록·검색·아이콘이 보이고, 고르면 아이콘 타일이 생긴다
- [ ] [직접 찾기…]로 exe·바로가기(lnk)를 골라도 실행된다
- [ ] 앱 타일 클릭: 꺼져 있으면 실행, 켜져 있으면 그 창이 앞으로(최소화돼 있으면 복원)
- [ ] 앱을 켜고 끄면 아이콘 아래 점이 따라 생기고 사라진다
- [ ] 지운 앱의 타일을 누르면 "앱을 찾을 수 없습니다" 알림과 함께 흐려진다
- [ ] 항목 추가 → 웹 주소(naver.com처럼 입력): 사이트 아이콘이 생기고 클릭하면 크롬 새 탭
- [ ] 우클릭 → 수정(종류 버튼 잠김) / 삭제(확인)
- [ ] 드래그로 순서 바꾸기, 재시작 후 유지. 패널의 ＋는 항상 끝
- [ ] 같은 타일을 빠르게 두 번 눌러도 한 번만 열린다

## 독 수정 모드
- [ ] 트레이 메뉴의 "독 모드" 바로 아래 "독 수정 모드"가 있고, 켜면 체크·판 빨간 테두리·안내 문구·－/＋/✓ 단추가 보인다 (패널 모드에서 누르면 독으로 바뀌며 켜짐)
- [ ] 수정 모드에서는 아이콘을 눌러도 열리지 않고 확대 효과가 없으며, 아이콘을 끌어 순서를 바꿀 수 있다 (수정 모드가 아니면 독 아이콘은 끌리지 않는다)
- [ ] 판 빈 곳에 이동 커서가 뜨고, 끌면 가장 가까운 가장자리(아래·위·왼쪽·오른쪽)에 붙어 그 가장자리를 따라 움직인다
- [ ] －/＋로 아이콘이 32~80px 사이에서 8px씩 바뀐다
- [ ] ✓를 누르면 수정 모드가 끝나고 메뉴 체크도 풀린다. 위치·가장자리·크기는 재시작 후 유지
- [ ] 트레이 메뉴에 독 위치(아래·위·왼쪽·오른쪽) 줄이 없다

## 표시
- [ ] 패널 제목·트레이 툴팁·확인 창 제목이 "Dock UI", 독 판 안 끝(마지막 아이콘 뒤)에 연한 "by ssenu" 두 줄
- [ ] 독 위에서 마우스를 좌우로 빠르게 움직여도 이름 말풍선이 잘리거나 잔상·깜빡임 없이 부드럽게 나타나고 사라진다 (125%·150% 배율에서도 모서리·테두리 또렷)
- [ ] 업데이트·끌어 놓기 알림 머리글이 "Dock UI" (이 버전을 설치한 뒤 첫 알림부터), exe 속성 → 자세히에 제품 이름 "Dock UI"
- [ ] 설치 후 시작 메뉴에 "Dock UI" 바로가기만 있고 옛 "YT Launcher" 바로가기는 지워진다
- [ ] 독 위에서 마우스를 좌우로 움직일 때 확대가 부드럽고(끊김 없음), 가리킨 아이콘만 살짝(1.3배)·바로 옆은 아주 조금 커진다

## 파일·폴더 항목
- [ ] 항목 추가 → 파일·폴더 카드 → [파일]/[폴더]로 고르면 경로가 보이고(길면 앞을 … 으로), 저장하면 셸 아이콘 타일이 생긴다
- [ ] 누르면 문서는 연결된 프로그램, 폴더는 탐색기로 열린다. 지운 파일은 "찾을 수 없습니다" 알림 후 흐리게
- [ ] 탐색기에서 문서·폴더를 끌어다 놓아도 파일 항목이 생긴다

## 끌어다 놓아 추가
- [ ] 탐색기에서 exe·바로가기(.lnk)를 독·패널에 끌어 올리면 테두리가 빨갛게 강조되고, 놓으면 앱 항목이 생긴다(아이콘 포함)
- [ ] 바탕화면의 인터넷 바로가기(.url), 크롬 주소창·링크를 끌어다 놓으면 웹 항목이 생긴다
- [ ] 이미 있는 앱·주소·파일은 건너뛰고 알린다
- [ ] 끌다가 밖으로 나가면 강조가 사라진다

## 안정성
- [ ] 절전 후 깨우기·모니터 끄고 켜기 뒤에도 독·패널이 그대로 그려진다 (로그에 "그리기 장치를 다시 만듭니다"가 있으면 복구된 것)

## 테마
- [ ] 패널 팔레트 버튼 → 색 원 4개(라이트·다크·세피아·투명)가 펼쳐지고, 고르면 부드럽게 바뀌며 재시작 후 유지
- [ ] 항목 추가 창: 종류 카드로 바뀌고, 빈 칸으로 저장하면 칸 아래 빨간 안내가 뜬다. Enter 저장·Esc 닫기, 제목 부분을 끌면 창이 움직인다
- [ ] 트레이 메뉴 → 테마 ▸ 에서도 고를 수 있고 지금 테마에 체크가 있다(독 모드는 여기서만)
- [ ] 판 뒤 바탕화면이 흐리게 비친다

## 설치·업데이트
- [ ] UAC 없이 설치되고 "설정 → 앱 → 설치된 앱"에 YT Launcher와 버전이 보인다
- [ ] 0.1.4가 실행 중인 상태에서 트레이 → 업데이트 설치 → 런처가 꺼졌다 0.2.0으로 다시 켜지고 "v0.2.0 버전으로 업데이트되었습니다" 알림
- [ ] 업데이트 후 0.1.x 타일이 그대로 있고(패널 모드로 시작), 설치 폴더에 `_internal`이 남지 않는다
- [ ] 앱에서 자동 실행을 끈 상태로 업데이트해도 재부팅 후 자동 실행되지 않는다
- [ ] 더 높은 버전 릴리스 후 30초 뒤 트레이 알림이 뜨고, 메뉴의 업데이트 설치로 넘어간다
- [ ] 새 버전이 있으면 독·패널 목록 끝에 초록 업데이트 단추(버전 배지)가 생긴다. 끌기·우클릭 메뉴가 안 되고, 다른 항목을 끌어도 늘 끝에 있다
- [ ] 업데이트 단추를 누르면 확인 창에 "바뀐 점" 목록(ci·docs 등 제외)이 보이고, 확인 뒤 배지가 0%→100% 진행률로 바뀌며 설치로 넘어간다. 최신 버전이면 단추가 없다
- [ ] 릴리스 페이지 본문에 이전 태그 이후 커밋 제목이 "바뀐 점"으로 올라와 있다
- [ ] 제거 후 프로그램 폴더와 Run 값이 사라지고 `%APPDATA%\YT-Launcher`는 남는다
