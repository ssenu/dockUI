# 릴리스 전 수동 점검표

빌드된 설치 프로그램으로 실제 Windows 11에서 확인한다.

## 독 모드
- [ ] 새 설치 첫 실행 시 화면 아래 가운데(작업표시줄 위 8px)에 독이 뜬다
- [ ] 작업표시줄에 아이콘이 없고 트레이 아이콘만 있다
- [ ] 다른 창을 열면 독이 그 뒤로 깔린다. Win+D 뒤에도 보인다
- [ ] 마우스를 올리면 아이콘이 물결처럼 커지고 이웃이 밀리며, 이름 말풍선이 화면 안쪽에 뜬다
- [ ] 독 위 빈 곳·독 옆 바탕화면 클릭이 막히지 않는다
- [ ] 독에는 항목 아이콘만 있다(항목이 없으면 ＋ 하나). 긴 이름에 마우스를 올려도 말풍선이 잘리지 않고 길면 … 으로 줄어든다(아래·왼쪽·오른쪽 독 모두)
- [ ] 트레이 메뉴 → 독 위치 위·왼쪽·오른쪽으로 옮겨 간다(왼쪽·오른쪽은 세로 독)
- [ ] 해상도나 작업표시줄 위치를 바꾸면 독이 다시 자리를 잡는다

## 패널 모드
- [ ] 트레이 메뉴 → 패널 모드로 바꾸면 우상단 창으로 바뀐다
- [ ] 이동·크기 조절, 위치 잠금, 위치·크기 초기화, 재시작 후 위치 복원

## 항목
- [ ] ＋(패널) 또는 트레이 메뉴 → 항목 추가… → 유튜브: 검색어 저장 → 클릭하면 크롬 최대화 창에 검색 결과(크롬이 켜져 있으면 새 탭)
- [ ] 항목 추가 → 앱 → [앱 고르기]: 목록·검색·아이콘이 보이고, 고르면 아이콘 타일이 생긴다
- [ ] [직접 찾기…]로 exe·바로가기(lnk)를 골라도 실행된다
- [ ] 앱 타일 클릭: 꺼져 있으면 실행, 켜져 있으면 그 창이 앞으로(최소화돼 있으면 복원)
- [ ] 앱을 켜고 끄면 아이콘 아래 점이 따라 생기고 사라진다
- [ ] 지운 앱의 타일을 누르면 "앱을 찾을 수 없습니다" 알림과 함께 흐려진다
- [ ] 항목 추가 → 웹 주소(naver.com처럼 입력): 사이트 아이콘이 생기고 클릭하면 크롬 새 탭
- [ ] 우클릭 → 수정(종류 버튼 잠김) / 삭제(확인)
- [ ] 드래그로 순서 바꾸기, 재시작 후 유지. 패널의 ＋는 항상 끝
- [ ] 같은 타일을 빠르게 두 번 눌러도 한 번만 열린다

## 테마
- [ ] 패널 팔레트 버튼 → 색 원 4개(라이트·다크·세피아·투명)가 펼쳐지고, 고르면 부드럽게 바뀌며 재시작 후 유지
- [ ] 항목 추가 창: 종류 카드로 바뀌고, 빈 칸으로 저장하면 칸 아래 빨간 안내가 뜬다. Enter 저장·Esc 닫기, 제목 부분을 끌면 창이 움직인다
- [ ] 트레이 메뉴 → 테마 ▸ 에서도 고를 수 있고 지금 테마에 체크가 있다(독 모드는 여기서만)
- [ ] 판 뒤 바탕화면이 흐리게 비친다

## 설치·업데이트
- [ ] UAC 없이 설치되고 "설정 → 앱 → 설치된 앱"에 YT Launcher와 버전이 보인다
- [ ] 0.1.4가 실행 중인 상태에서 트레이 → 업데이트 설치 → 런처가 꺼졌다 0.2.0으로 다시 켜지고 "v0.2.0 버전으로 업데이트되었습니다" 알림
- [ ] 업데이트 후 0.1.x 타일이 그대로 있고(패널 모드로 시작), 설치 폴더에 `_internal`이 남지 않는다
- [ ] 앱에서 자동 실행을 끈 상태로 업데이트해도 재부팅 후 자동 실행되지 않는다
- [ ] 더 높은 버전 릴리스 후 30초 뒤 트레이 알림이 뜨고, 메뉴의 업데이트 설치로 넘어간다
- [ ] 제거 후 프로그램 폴더와 Run 값이 사라지고 `%APPDATA%\YT-Launcher`는 남는다
